# Claude & Codex Usage Monitor

Claude Code や Codex を使っている人向けの、軽量な Windows タスクバーウィジェットです。

タスクバーに常駐し、Claude / Codex の使用量ウィンドウの残りを表示します。ターミナルやプロバイダーのサイトを開く必要はありません。

> 本プロジェクトは、Craig Constable 氏による [Claude Code Usage Monitor](https://github.com/CodeZeno/Claude-Code-Usage-Monitor) を基にした派生物で、MIT ライセンスで配布されています。帰属の詳細は [LICENSE](LICENSE) を参照してください。

## 主な機能

- 現在の **5時間**ウィンドウのバー（5h）
- 現在の **7日間**ウィンドウのバー（7d）
- Claude と並べて表示できる任意の Codex 使用量バー
- 各上限がリセットされるまでのライブカウントダウン
- Windows タスクバーに直接置かれる小さなネイティブウィジェット
- **切り替え可能なバースタイル**：セグメント / ミニマルフラット / グラデーション / レトロピクセル
- **ピクセルキャラクター**（猫／犬）がウィジェット上を歩き回り、使用量に反応
- 有効なモデルの使用率を示すシステムトレイアイコンのバッジ
- トレイアイコン左クリックでウィジェットの表示/非表示を切り替え
- 右クリックでモデル・バースタイル・キャラクター・更新・更新間隔・言語・スタートアップ・アップデートを設定

## 対象ユーザー

このアプリは、すでに **Claude Code（CLI または App）をインストールしてサインイン済み**の Windows ユーザー向けです。

Codex 対応は任意です。Codex 使用量を表示するには、Codex CLI をインストールしてサインインし、右クリックの **Models** メニューから Codex を有効にしてください。

「上限までどれくらいか」をいつでも見えるシンプルな表示が欲しい場合に最適です。

## 必要要件

- Windows 10 または Windows 11
- **Claude Code（CLI または App）をインストールしてサインイン済み**であること
- 任意：Codex 使用量を見たい場合は Codex CLI のインストールとサインイン

> ### ⚠️ まず Claude Code か Codex のインストールが必要です
>
> このウィジェットは、**Claude Code（または Codex）がインストール・サインインされるまで使用量を一切表示しません。**
> 自前でログインや使用量取得を行うわけではなく、Claude Code / Codex がサインイン時に作成する認証情報を読み取って動作します。どちらも未設定の場合、バーは `!` を表示し、サインインを促す通知が出ます。
>
> 先に公式ツールをインストールし、サインインしてください：
>
> - **Claude Code** — https://github.com/anthropics/claude-code （インストール後、`claude` を実行して `/login`）
> - **Codex CLI** — https://github.com/openai/codex （インストール後、CLI のサインインを完了）
>
> サインインを済ませた**後**にこのアプリを起動してください。以降は自動的に使用量を取得します。

WSL 上で Claude Code を使っている場合も対応しています。Windows 側・WSL 側のどちらの認証情報も読み取れます。

## インストール

[Releases](https://github.com/Ch1nzo/claude-codex-usage-monitor/releases) ページから最新のインストーラー（`claude-codex-usage-monitor-setup.exe`）をダウンロードして実行してください。

インストーラーは**ユーザー単位で、管理者権限不要**です。以下を行います：

- `%LOCALAPPDATA%\Programs\ClaudeCodexUsageMonitor` にインストール
- **スタートメニュー**にショートカットを追加
- **設定 → アプリ → インストールされているアプリ**に登録し、通常の方法でアンインストール可能に
- セットアップ完了時に**「起動」**チェックボックスを表示

アンインストールは **設定 → アプリ → インストールされているアプリ → Claude & Codex Usage Monitor → アンインストール**（または同梱の `uninstall.exe`）から行えます。

## 使い方

スタートメニューから **Claude & Codex Usage Monitor** を起動します（またはセットアップ完了時の「起動」にチェック）。

起動するとタスクバーに表示され、通知領域に1つ以上のトレイアイコンが出ます。

- 左の仕切りをドラッグするとウィジェットを移動できます
- ウィジェットまたはトレイアイコンを右クリックで、モデル・バースタイル・キャラクター・更新・更新間隔・Windows起動時に開始・位置リセット・言語・アップデート・終了
- トレイアイコン左クリックでウィジェットの表示/非表示を切り替え
- サインイン時に自動起動したい場合は、右クリックメニューの `Windows と同時に開始` を有効に

### Models（モデル）

右クリックの **Models** メニューで表示対象を選べます：

- **Claude Code** はデフォルトで有効
- **Codex** は Claude Code と並べて、または単独で表示可能

両方表示すると、各モデルが専用の使用量バーと対応するテキスト色を持ちます。

### Bar Style（バースタイル）

右クリックの **Bar Style** メニューでバーの描画方法を切り替えられます：

- **Segmented blocks** — デフォルト。モデルのブランドカラー
- **Minimal flat** — 連続した1本のバー
- **Gradient glow** — 光るグラデーション
- **Retro pixel** — ピクセルブロック風のメーター

デフォルト以外のスタイルは、使用率のしきい値で色分けします（緑 → 黄 → 橙 → 赤）。選択は保存され、即座に反映されます。

### Characters（キャラクター）

右クリックの **Characters** メニューで、ウィジェットのすぐ上を歩き回る小さなピクセルキャラクターを表示できます：

- キャラクターの表示/非表示
- **猫 / 犬 / 両方** の選択
- 色（猫：オレンジ/グレー、犬：茶/黒）の選択

キャラクターはidle・歩行・まばたきをし、使用量に反応します。余裕があるときは励まし、80%超でソフト警告、90%超で緊急警告、リセット時に「お疲れさま」を表示。キャラに**ホバー**すると少し待って反応し、**クリック**すると素早く反応します（猫はクール、犬は元気）。メッセージは日本語と英語に対応（他の言語は英語にフォールバック）。キャラクターはデフォルトで表示されます。

### システムトレイアイコン

トレイアイコンは現在の5時間使用率をパーセントのバッジで表示します。

Claude Code と Codex の両方が有効な場合、アイコンは2つ（Claude 用と Codex 用）表示されます。1モデルのみなら1つです。

Claude のトレイアイコンは Claude バーと同じ暖色系、Codex のトレイアイコンは白黒のバッジスタイルです。

トレイアイコンにホバーすると、そのモデルの使用量が表示されます。

## 診断

起動や表示の問題を調べたい場合：

```powershell
claude-codex-usage-monitor --diagnose
```

ログファイルは次の場所に書き出されます：

```text
%TEMP%\claude-codex-usage-monitor.log
```

設定は次の場所に保存されます：

```text
%APPDATA%\ClaudeCodexUsageMonitor\settings.json
```

## アカウント対応

このアプリは Claude Code 自体が対応するアカウント種別と同じものに対応します。

- **対応：** Pro、Max、Teams、Enterprise、Console アカウント
- **非対応：** 無料の Claude.ai プラン

将来 Anthropic が Claude Code の対応範囲を変更した場合も、同じ認証付きエンドポイントで使用量が公開され続ける限り、本アプリは Claude Code の対応に追随します。

## プライバシーとセキュリティ

本プロジェクトは**オープンソース**であり、動作を正確に確認できます。

アプリが読み取るもの：

- ローカルの Claude Code OAuth 認証情報（`~/.claude/.credentials.json`）
- 必要に応じて、インストール済み WSL ディストロ内の同じ認証情報ファイル
- Codex 有効時は、ローカルの Codex 認証情報（`$CODEX_HOME/auth.json` または `~/.codex/auth.json`）

アプリがネットワークに送信するもの：

- 使用量とレート制限情報を取得するための Anthropic の Claude エンドポイントへのリクエスト
- Codex 有効時は、ChatGPT の Codex 使用量エンドポイントへのリクエスト
- アップデート確認/自己更新機能を使う場合のみ、GitHub へのリクエスト
- `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` などのプロキシ環境変数が設定されていれば、それ経由で送信される場合があります

アプリがローカルに保存するもの：

- ウィジェットの位置
- ポーリング間隔
- 言語設定
- 最終アップデート確認時刻
- 表示モデルの設定
- バースタイルの設定
- キャラクターの設定（表示/非表示、猫/犬/両方）

アプリが**行わない**こと：

- 認証情報を他のサーバーへ送信しない
- 独自のバックエンドサービスを使わない
- アナリティクスやテレメトリを収集しない
- プロジェクトファイルをアップロードしない
- Codex の認証情報ファイルを直接編集しない

注記：

- Claude Code のトークンが期限切れの場合、バックグラウンドでローカルの Claude CLI に更新を依頼することがあります
- Codex のトークンが期限切れの場合、バックグラウンドでローカルの Codex CLI に更新を依頼することがあります。本アプリ自体は `auth.json` を書き込みません。認証情報の更新は Codex CLI が行います
- ポータブル版は、本リポジトリの最新リリースをダウンロードして自己更新できます
- プロキシ経由の使用量リクエストには TLS 接続内に OAuth ベアラートークンが含まれるため、信頼できるプロキシのみを使用してください

## 仕組み

本モニターは：

1. 有効なモデルのログイン認証情報を見つけ
2. Anthropic / ChatGPT から現在の使用量を読み取り
3. その結果を Windows タスクバーに直接表示し
4. バックグラウンドで定期的に更新します

新しい使用量エンドポイントが利用できない場合は、Claude の Messages API が返すレート制限ヘッダの読み取りにフォールバックします。
